# 末日之城（Doomsday City）

方块风格的守城打僵尸游戏（Three.js r128，单文件）。站在城墙上射击、遥控重机枪、招募守军，守住身后的村庄。

## 运行
直接用浏览器打开 `www/index.html`（同目录的 `three.min.js` 保证离线可玩）。

## 操作（电脑）
WASD 移动 · Shift 冲刺 · 鼠标瞄准 · 左键射击 · 右键瞄准/开镜 · R 换弹 · 1-4 切枪
F 遥控机枪（1-3 切换）· T 标记集火目标 · B 商店 · N 立即开战 · Esc 暂停

手机：左摇杆移动，右半屏拖动视角，右下角按钮操作。`www/` 可作为 Capacitor 的 webDir 打包 APK。
