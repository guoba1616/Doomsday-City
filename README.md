# 末日之城（Doomsday City）

方块风格的架炮守城打僵尸游戏（Three.js r128，单文件）。在城墙上架设炮台、招募炮手、亲手开炮，守住身后的村庄。

## 运行
直接用浏览器打开 `www/index.html`（同目录的 `three.min.js` 保证离线可玩）。

## 玩法
玩家不拿枪，在城墙上走动，选垛口架设炮台：**重机枪 / 霰弹炮 / 火箭炮 / 反器材炮**。
招募村民当**炮手**自动操作炮台，也可以亲手操控任意一座。城墙耐久归零 = 城破。

## 操作（电脑）
WASD 走动 · 鼠标看 · 右键望远镜 · **Q** 在脚下垛口建造（1-4 选类型）
炮台旁：**G** 派炮手 · **U** 升级 · **X** 拆除（按两次）
**F** 亲手操控炮台（A/D 或滚轮切换，F 离开）· **T** 命令炮手集火 · **B** 商店（修墙 / 工匠 / 炮手训练）· **N** 开战 · Esc 暂停

手机：左摇杆走动，右半屏拖动视角，右侧按钮随情境出现。`www/` 可作为 Capacitor 的 webDir 打包 APK。
